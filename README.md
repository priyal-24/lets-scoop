# Let's Scoop 🍦

A modern and visually appealing ice cream website developed using HTML and CSS. The project focuses on creating an engaging user experience with a clean design, responsive layout, and attractive product presentation.

## 🚀 Features

- Responsive and user-friendly interface
- Modern landing page design
- Ice cream product showcase section
- Smooth navigation experience
- Font Awesome icons integration
- Organized project structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

```
│
├── images/
├── index.html
└── style1.css
```
